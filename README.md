# Esports Performance Predictor

Predicts **APM** (actions per minute) and **Reaction Time** from Age, Sleep Hours,
Energy Drinks, and Game Genre, using a linear regression fit on the
`esports_gaming_biometrics_250k.csv` dataset.

## How to run

```bash
pip install -r requirements.txt
python3 analysis.py   # trains the model, writes model.json
python3 app.py         # starts the web app
```

Then open http://127.0.0.1:5000 in a browser. Move the sliders / change the
genre to see predicted APM and reaction time update live.

## Files

- `analysis.py` — loads the dataset, fits the regression models (train/test
  split, R², residual std), writes `model.json`.
- `app.py` — Flask backend exposing `/api/predict` and serving the frontend.
- `index.html` — sliders + live gauges for APM and reaction time.
- `model.json` — generated by `analysis.py` (coefficients, R², ranges).
- `data/esports_gaming_biometrics_250k.csv` — source dataset.
